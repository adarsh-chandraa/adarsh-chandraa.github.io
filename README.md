## Publish with GitHub Pages
1. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html` and the `assets` folder (keep the folder structure unchanged).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
5. Wait for deployment and open `https://YOUR-GITHUB-USERNAME.github.io/`.
